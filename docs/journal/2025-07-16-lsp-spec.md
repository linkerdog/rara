# LSP Integration Spec

## What

Researched how OpenCode, Codex CLI, and Claude Code integrate LSP, then
wrote `docs/features/lsp-integration.md`.

## Key Findings

| Tool | LSP Status | Approach |
|------|-----------|----------|
| OpenCode | ✅ Implemented | 30+ built-in servers, auto-detect, diagnostics → LLM |
| Codex CLI | 🔜 Proposed | Issue #8745, same design as OpenCode |
| Claude Code | ❌ Not implemented | Issue #24249, wants IDE bridge |

## Design for RARA

- Phase 1: rust-analyzer bridge (lazy spawn, diagnostics parsing)
- Phase 2: System context injection (# LSP Diagnostics block)
- Phase 3: Configuration surface
- Phase 4: Multi-language support

## Remains

- Implementation (~300 lines across 4 phases)
- Multi-language detection table
- Custom LSP server config
