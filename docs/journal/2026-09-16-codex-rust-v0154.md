# Codex Rust v0.154 Upgrade

**Date**: 2026-09-16
**Scope**: Update RARA's direct upstream Codex Rust dependencies.

## What Changed

- Advanced `codex-execpolicy`, `codex-http-client`, `codex-login`, and
  `codex-models-manager` from `rust-v0.147.0` to `rust-v0.154.0`.
- Refreshed the lockfile, including the transitive `lru` update required by the
  newer Codex dependency graph.
- Updated OAuth test fixtures for Codex's new optional
  `bedrock_access_keys` auth storage field.

## Why

RARA embeds Codex Rust types for authentication, model metadata, HTTP, and
execution policy. Keeping all four direct dependencies on one current upstream
tag avoids mixing incompatible types and lets the bundled integrations track
the installed Codex release line.

- `cargo test --locked deepseek`
